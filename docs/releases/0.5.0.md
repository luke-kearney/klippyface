> [!WARNING]
> **The two ESP32-S3 firmware builds are completely untested on hardware.** They compile and are published so they can be tried, but have never run on a real Waveshare board, nor have their ST7789 / GC9A01 display drivers. Expect problems; please report what you see (serial log + photo) on [#21](https://github.com/luke-kearney/klippyface/issues/21) (LCD-1.69) or [#29](https://github.com/luke-kearney/klippyface/issues/29) (LCD-1.28). The classic ESP32 build is tested.

## Which file do I need?

| File | Device | Status |
|------|--------|--------|
| `klippyface-firmware-0.5.0-esp32dev.bin` / `-full.bin` | Classic ESP32 DevKit (ESP-WROOM-32) with an SH1106 OLED or HX8347D parallel TFT | ✅ Tested |
| `klippyface-firmware-0.5.0-esp32s3-ws-lcd169.bin` / `-full.bin` | Waveshare ESP32-S3-Touch-LCD-1.69 (ESP32-S3R8, ST7789V2 240×280) | ⚠️ **Completely untested** |
| `klippyface-firmware-0.5.0-esp32s3-ws-lcd128.bin` / `-full.bin` | Waveshare ESP32-S3-LCD-1.28 (ESP32-S3R2, GC9A01 240×240 round) | ⚠️ **Completely untested** |
| `klippyface-server-0.5.0-linux-arm64.tar.gz` | Companion server + Web UI, 64-bit ARM Linux (e.g. Raspberry Pi) | Same code as x64; ARM build not run by us |
| `klippyface-server-0.5.0-linux-x64.tar.gz` | Companion server + Web UI, x86-64 Linux | ✅ Tested |

- **`-full.bin`** is for a blank or erased board: `esptool write-flash 0x0 <file>`
- **`.bin`** (no `-full`) is the app only, for updating a board that already runs Klippyface
- A firmware build only works on the device it's named for: the S3 builds won't boot on a classic ESP32, and the two S3 builds aren't interchangeable (different PSRAM type and USB serial)
- Firmware files now carry the board name. The classic build used to be `klippyface-firmware-<version>.bin`; it's now `…-esp32dev.bin`

## Highlights

- **ESP32-S3 support** for two Waveshare boards, each with its own build ([#20](https://github.com/luke-kearney/klippyface/issues/20)) — untested, see above
- **SPI colour display drivers**: ST7789 / ST7789V2 and GC9A01 round panels, sharing one driver with the HX8347D
- **No more flashing on frame changes** on TFTs without PSRAM: frames are rendered off-screen in bands and pushed whole
- **Board presets** in the display dialog; nodes report their board so a new display starts from the right preset ([#30](https://github.com/luke-kearney/klippyface/issues/30))
- **Starter faces per display size** (320×240, 240×320, 240×280, round 240×240), plus a size setting for text and sprites ([#32](https://github.com/luke-kearney/klippyface/issues/32)). Use the ✨ button on a display to switch it to faces sized for it

## Upgrading

- **Server:** database migrations run automatically on start (new columns only)
- **Firmware:** update nodes to 0.5.0 so element sizes render; older firmware draws everything at size 1
