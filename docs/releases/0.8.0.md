> [!TIP]
> **Install a display from your browser:** open the **[Klippyface Flasher](https://luke-kearney.github.io/klippyface/)** in Chrome or Edge, pick your board, click **Install**, then enter your WiFi in the same page. The display finds the server and shows up on the **Nodes** page to accept. No files to download and no setup hotspot. New to Klippyface? Follow [Getting Started](https://github.com/luke-kearney/klippyface/blob/master/docs/getting-started.md).

> [!WARNING]
> **The two ESP32-S3 firmware builds are still untested on hardware**, as are their ST7789 / GC9A01 drivers and, new in this release, setting WiFi from the flasher over their built-in USB. Please report what you see (serial log + photo) on [#21](https://github.com/luke-kearney/klippyface/issues/21) (LCD-1.69) or [#29](https://github.com/luke-kearney/klippyface/issues/29) (LCD-1.28). The classic ESP32 build is tested.

## Which file do I need?

Using the [flasher](https://luke-kearney.github.io/klippyface/)? It picks the firmware for you; you only need a server file.

| File | Device | Status |
|------|--------|--------|
| `klippyface-firmware-0.8.0-esp32dev.bin` / `-full.bin` | Classic ESP32 DevKit (ESP-WROOM-32) with an SH1106 OLED or HX8347D parallel TFT | ✅ Tested |
| `klippyface-firmware-0.8.0-esp32s3-ws-lcd169.bin` / `-full.bin` | Waveshare ESP32-S3-Touch-LCD-1.69 (ESP32-S3R8, ST7789V2 240×280) | ⚠️ Untested |
| `klippyface-firmware-0.8.0-esp32s3-ws-lcd128.bin` / `-full.bin` | Waveshare ESP32-S3-LCD-1.28 (ESP32-S3R2, GC9A01 240×240 round) | ⚠️ Untested |
| `docker-compose.yml` | Companion server in Docker, Linux x86-64 or ARM64: `docker compose up -d` in its folder | ✅ Tested on x86-64 |
| `klippyface-server-0.8.0-linux-x64.tar.gz` | Companion server + Web UI, x86-64 Linux | ✅ Tested |
| `klippyface-server-0.8.0-linux-arm64.tar.gz` | Companion server + Web UI, 64-bit ARM Linux (e.g. Raspberry Pi) | Same code as x64; ARM build not run by us |
| `klippyface-server-0.8.0-win-x64.zip` | Companion server + Web UI, Windows x64 | Not run by us |

- **`-full.bin`** is for a blank or erased board: flash it at `0x0` with `esptool write-flash 0x0 <file>` or [ESPTool](https://esptool.spacehuhn.com/)
- **`.bin`** (no `-full`) is the app only, for updating a board that already runs Klippyface: flash it at `0x10000` and its settings are kept
- A firmware build only works on the device it's named for

## Highlights

- **Browser flasher** ([#24](https://github.com/luke-kearney/klippyface/issues/24)): https://luke-kearney.github.io/klippyface/ always serves the latest release. Pick a board (both Waveshare boards are ESP32-S3, so the flasher can't tell them apart: choose the right one) and click **Install**. Chrome or Edge on a desktop or laptop; other browsers get the manual instructions
- **WiFi from the flasher** ([#53](https://github.com/luke-kearney/klippyface/issues/53)): the firmware speaks Improv Wi-Fi over USB, so right after installing the flasher asks for your network (with a list to pick from) and checks the board can connect before saving. The server address is left blank, so the display finds the server. The `Klippyface-Setup` hotspot still works as before
- **Getting started guide**: [docs/getting-started.md](https://github.com/luke-kearney/klippyface/blob/master/docs/getting-started.md), from installing the server to an accepted display, with troubleshooting

## Upgrading

1. **Server:** no changes that need action. Update as usual (`docker compose pull && docker compose up -d`, or extract the new release)
2. **Displays:** optional, needed only for setting WiFi from the flasher later. Either:
   - use the flasher: it **resets the display's settings** (WiFi, name, server address), so enter WiFi again when it asks. The server still knows the display, so there's nothing to accept again. ([#55](https://github.com/luke-kearney/klippyface/issues/55) will make updates keep settings)
   - or flash `klippyface-firmware-0.8.0-<board>.bin` at `0x10000` by hand, which keeps them

0.7.0 displays keep working with a 0.8.0 server.

## Not tested on hardware

- The ESP32-S3 builds, including Improv over their native USB (see above)
- The ARM64 server build and Docker image on a real ARM board
- The Windows server
